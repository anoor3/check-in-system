# Check-In System

This repository hosts a placeholder React application built with Vite so deployments succeed
while the full check-in experience is implemented. It includes Supabase client dependencies so
that authentication helpers can be wired up once the UI is ready.

## Getting started

```bash
npm install
npm run dev
```

## Building for production

```bash
npm run build
```

The production-ready assets are emitted to the `dist/` directory.
